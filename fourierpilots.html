FourierPilots · behavior cloning

Improving behavior cloning of an xPilot agent with the discrete Fourier transform

Prior work shows signal-processing transforms inside neural networks can improve the overall agent. This project applies that idea to a behavior-cloning agent for xPilot.

  • Discrete Fourier Transform
  • DCT

Method

High-dimensional observations from the xPilot environment are compressed with a Fast Fourier Transform (FFT) or Discrete Cosine Transform (DCT) before reaching a neural-network controller.

The controller is trained by behavior cloning on data generated by a rule-based agent. A baseline network trained on uncompressed observations is the comparison. Both are evaluated on accuracy and validation loss.

Results

  • On time-series data, MLPCosineTime (a single DCT) outperformed every other signal-processing variant.
  • On independent data, MLPDoubleCosineTime (a double DCT) outperformed every other signal-processing variant.
